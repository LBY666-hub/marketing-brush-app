# 市场营销刷题 · 使用说明

一套**离线可用的市场营销刷题小程序（PWA）**，内置 **3 套试卷、共 270 题**（每套：单选 30 + 多选 30 + 判断 20 + 案例分析 10）。每题含**题目 / 选项 / 正确答案 / 知识点详解**。

---

## 一、点击哪里打开

| 方式 | 操作 | 说明 |
|------|------|------|
| **推荐** | **双击 `启动.bat`** | 会自动用默认浏览器打开刷题页面，最简单 |
| 手动 | 双击 `index.html` | 直接用浏览器打开（`file://` 方式） |
| 在线版 | 访问本仓库的 GitHub Pages 地址 | 用于**手机安装**（见下文「装到手机」） |

> `启动.bat` 只负责打开页面，无任何联网行为。

---

## 二、运行需要什么

- 一台电脑或手机 + **现代浏览器**（推荐 Chrome / Edge / Safari）。
- **无需安装任何软件**，无需账号，无需联网（本地打开时完全离线）。
- 若要用 `启动.bat`：Windows 系统双击即可。

---

## 三、网络配置

| 场景 | 是否联网 | 详情 |
|------|----------|------|
| **本地打开**（双击 index.html / 启动.bat） | **否** | 纯本地，不访问任何外部接口、不联网 |
| **手机安装（PWA）** | **需要 HTTPS** | 需通过 GitHub Pages 等 HTTPS 静态托管访问，才能「添加到主屏幕」+ 离线缓存 |
| **App 自身** | 全程无网络请求 | 不调用任何 API，不采集、不上传任何数据 |

**一句话**：这个网页**不联网也能用**；只有「把它安装到手机」这一步需要借一个 HTTPS 网址（GitHub Pages）。

---

## 四、数据存储与隐私（务必了解）

- 做题记录、错题本、统计、主题偏好，全部保存在**你当前设备的浏览器本地存储（localStorage）**里，**不会上传服务器、不会传到 GitHub、别人也看不到**。
- 记录**按设备和浏览器隔离**：手机、电脑、不同浏览器互不相同；换设备需用 App 里「**更多 → 导出记录**」备份迁移。
- **清理浏览器缓存/清除站点数据**后记录会丢失，建议定期导出备份。
- 因为无后端，也**无法查看其他人的做题情况**——这是「纯前端 + 本地存储」的天然特性。

## 五、功能一览

- **刷题**：顺序练习 / 单选专练 / 多选专练 / 判断专练 / 案例专练 / 随机练习 / 错题重练 / 未做重练
- **错题本**：自动汇总做错的题，可单题重做或整体重练
- **统计**：已做 / 答对 / 答错、总体正确率、分题型正确率
- **更多**：导出记录（备份/迁移）、清空记录、主题切换（顶部 🌙/☀️ 按钮，深色/浅色）

## 六、装到手机（PWA：添加到主屏幕，离线可用）

1. 把本仓库 **`刷题App` 文件夹内容**发布到 GitHub Pages（或任意 HTTPS 静态托管），得到一个网址。
2. 手机浏览器打开该网址：
   - **安卓（Chrome）**：菜单 →「添加到主屏幕」。
   - **iPhone（Safari）**：分享 →「添加到主屏幕」。
3. 之后桌面出现图标，点开即全屏运行；首次加载后**断网也能刷**（离线缓存）。

## 七、怎么改题 / 加题

题库在 `data/paperN.js` 里（N 为 1/2/3），每道题格式如下，直接改 `q`（题目）、`o`（选项数组）、`a`（答案）、`note`（知识点详解）即可：

```js
{ q: '题目内容', o: ['A. 选项一','B. 选项二','C. 选项三','D. 选项四'], a: 'B', note: '知识点详解说明' }
```

- 单选题：`a` 填单个字母（如 `B`）。
- 多选 / 案例分析：`a` 填多个字母（如 `ABCD`）。
- 判断题：`a` 填 `√` 或 `×`。
- 改完保存，刷新页面即生效。

## 八、常见问题（FAQ）

**Q1：双击 index.html 打开后，首页显示正常吗？**
A：正常。但 `file://` 方式下「离线缓存/装手机」功能不生效（这些需要 HTTPS）。日常刷题不受影响。

**Q2：为什么换了手机/浏览器，做题记录没了？**
A：记录存在单台设备、单个浏览器里，不会同步。用「更多 → 导出记录」复制保存，可在新设备找回。

**Q3：点「导出记录」提示失败？**
A：部分浏览器限制剪贴板，可改用 App 内的备用复制方式，或手动复制弹窗内容。

**Q4：页面白屏 / 打不开？**
A：先确认用现代浏览器（Chrome/Edge/Safari）；确认文件完整、没有改动 HTML 结构；必要时强制刷新（Ctrl+Shift+R）。

**Q5：答案 / 详解是官方来源吗？**
A：答案以你的试卷答案为准（已与答案文档逐题核对一致）；知识点详解由 AI 依据市场营销知识编写，个别可自行在 `data/paperN.js` 中修改。
